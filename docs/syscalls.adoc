== システムコール
MIRACOSのBCOSカーネルはシステムコール（ファンクションコール）ABIを持ち、ユーザープログラムはカーネルが提供する機能をシステムコールによって利用することができます。ABIはシステムコールの呼び出し手順および各システムコール関数のシステムコール番号・引数・戻り値の定義セットから構成されます。

=== 呼び出し手順
MIRACOSのシステムコールは以下の手順で行います。

. レジスタやゼロページレジスタに引数 (パラメータ) を設定
. Xレジスタにシステムコール番号を1回左シフトした値（システムコール番号の2倍の値）を格納
. `JSR $0603` を実行

システムコールからリターンしたとき、すべてのレジスタは破壊されているか、または戻り値を格納しています。原則としてゼロページレジスタは保存されますが、一部のシステムコールは特定のゼロページレジスタを破壊、または戻り値の格納先として使用します。

=== `CON_RAWIN` (3) コンソール生入力
==== 引数
[{syscall_reg2col_table}]
|===
|`A`
a|動作モード

[cols="^1,12,8"]
!===
!`0`
!`BHA_CON_RAWIN_GetState`
!コンソール入力バッファの残量を取得する

!`1`
!`BHA_CON_RAWIN_NoWaitNoEcho`
!コンソール入力があれば返すがエコーしない

!`2`
!`BHA_CON_RAWIN_WaitAndNoEcho`
!コンソール入力があるまで待機して返し、エコーしない
!===
|===

==== 戻り値
[{syscall_reg2col_table}]
|===
|`A`
a|

[cols="1,1"]
!===
!`BHA_CON_RAWIN_GetState` 指定時
!コンソール入力バッファ残量

!バッファが空の場合
!`$00`

!その他の場合
!コンソールから入力された文字
!===

|`Z` フラグ
|戻り値 `A=$00` でセット
|===

==== 破壊されるレジスタ
不明

==== 機能・解説
Aレジスタで指定した動作モードに応じて、コンソール入力への低レベルアクセスを行います。

`BHA_CON_RAWIN_GetState` 指定時 (`A=0`) 、コンソール入力バッファに溜まっているバイト数が取得され、Aレジスタで返されます。さらに、バッファが空でA=0となった場合はZフラグがセットされます。

`BHA_CON_RAWIN_NoWaitNoEcho` 指定時 (`A=1`) 、コンソール入力バッファが空でなければバッファから一文字を取り出して返します。バッファが空の場合は即座に$00を返します。

`BHA_CON_RAWIN_WaitAndNoEcho` 指定時 (`A=2`) 、コンソール入力バッファが空でなければバッファから一文字を取り出して返します。バッファが空の場合はコンソール入力が発生するまで待ち、入力された内容を返します。

=== `FS_OPEN` (5)
==== 引数
[{syscall_reg2col_table}]
|===
|`AY`
|ファイルパスのゼロ終端文字列またはFINFO構造体のポインタ

|`ZR0`
a|動作モードフラグ

[cols="^1,4,4"]
!===
!`bit0`
!`O_TRUNC`
!セット=内容を廃棄してからオープン
!===
|===

==== 戻り値
[{syscall_reg2col_table}]
|===
|`A`
|ファイル記述子

|`Cフラグ`
|セット=エラー発生
|===

==== 破壊されるレジスタ
不明

==== 機能・解説
AYレジスタの値はファイルパス文字列またはFINFO構造体を指すポインタとして解釈されます。BCOSは指定されたファイルに対してオープンを試みます。指定されたファイルが既存でありかつZR0がセットされている場合はファイルの内容が破棄されてからオープンします。成功した場合は1バイトの整数であるファイル記述子がAレジスタで返り、Cフラグがクリアされます。失敗した場合はエラーが報告され、Cフラグがセットされます。

=== `CON_IN_STR` (7)
==== 引数
[{syscall_reg2col_table}]
|===
|`AY`
|文字列バッファのポインタ

|`ZR0L`
|バッファの長さ（1〜255）
|===

==== 戻り値
[{syscall_reg2col_table}]
|===
|`A`
|入力された字数
|===

==== 破壊されるレジスタ
不明

==== 機能・解説
AYレジスタが指定する領域にコンソール入力が書き込まれます。書き込みは、ZR0Lで指定されたバッファの上限に達するか、コンソールに改行が入力されるまで継続します。
